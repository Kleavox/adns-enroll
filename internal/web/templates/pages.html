Set it up

  • Chrome, Edge: Settings, Privacy and security, Security, Use secure DNS, custom; paste the address.
  • Firefox: Settings, Privacy & Security, DNS over HTTPS, Max Protection, custom; paste the address.
  • Phones: use a browser or an app that takes a DNS-over-HTTPS address. Android's Private DNS needs a different kind of address, which this server does not offer.
